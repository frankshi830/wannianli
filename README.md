# 中华万年历

公历农历对照、黄历吉凶宜忌、十二时辰吉凶查询与行程备注提醒的 PWA 应用。
黄历内容仅供传统民俗文化交流参考。

## 在线使用

<https://frankshi830.github.io/wannianli/>

## 安装到手机

- **iPhone**：Safari 打开上方链接 → 分享 → 「添加到主屏幕」
- **安卓**：Chrome 打开链接 → 菜单 → 「添加到主屏幕」/「安装应用」

安装后支持离线使用，行程提醒功能在授予通知权限后生效。

## 功能

- 1901–2100 年公历/农历对照月历，节日节气标记
- 每日黄历：值神吉凶、十二建星、星宿、冲煞、宜忌、彭祖百忌、方位、纳音
- 十二时辰吉凶（实时高亮当前时辰）
- 行程备注：按日管理事项，可选时间并开启到点提醒（数据保存在本机）

## 技术

React + TypeScript + Vite + Tailwind CSS + Capacitor，历法计算基于 lunar-typescript。

推送到 main 分支后由 GitHub Actions 自动构建并部署到 GitHub Pages。
